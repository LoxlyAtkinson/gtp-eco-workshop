# Scroll Craft production score

Grammar: **guided field study**, custom to a presenter-led 15-scene learning journey. Unlike a filmic one-shot, it keeps direct section entry, notes and overview; unlike chaptered editorial, it carries one object across boundaries; unlike continuous worldflight, it allows readable teaching stations. Live surface lacks the cinematic object arc; typographic poster lacks 3D ad proof; gallery/catalog lacks causal teaching; split stage only fits the voice comparison; rhythmic cutlist is too fast for a 60-minute workshop. The section rail is a map, not a counter for its own sake. Signature move: the evidence thread changes form across the complete funnel.

Registry check: `scrollcraft/FINGERPRINTS.md` was newly seeded and has no prior build rows. Fingerprint comparison is therefore vacuous for this first build; record the final row only after implementation and verification.
