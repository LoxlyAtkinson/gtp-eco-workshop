Add a skill to Claude in 3 steps

  1. Switch on file creation (1 minute)

    Open claude.ai on a computer and sign in. The free plan works.

    Go to Settings > Capabilities and switch on Code execution and file creation. In the newer layout it is called Create and edit files.

  2. Upload one skill (1 minute per skill)

    In Claude, go to Customize > Skills. Click +, then + Create skill, then Upload a skill.

    Choose one skill zip, for example campaign-plan.zip. Upload it as it is. Don't unzip it. One zip is one skill.

  3. Use it (1 minute)

    Check that the switch next to the skill is on. Start a new chat and name the skill in your request:

    Use the campaign-plan skill to plan four weeks of Facebook and WhatsApp posts for my bakery in Durban.

Official steps: Use skills in Claude (Claude Help Center). Using Claude Code instead? Copy the skill folders into ~/.claude/skills/.
