Where skills work

Claude.ai, web or desktop app

Any plan, the free one too. Code execution must be switched on. Do the setup on a computer.

Claude Code

Anthropic's coding tool that runs in a terminal. Two commands install all eight.

Install on Claude.ai (about 10 minutes)

  1. Unzip the pack. Open the folder called upload-to-claude. Inside are eight small zips, one per skill.

  2. Switch on code execution. In Claude, open Settings > Capabilities and turn on Code execution and file creation. Some accounts call it Create and edit files.

  3. Upload a skill. Go to Customize > Skills. Click +, then + Create skill, then Upload a skill.

    Pick one zip, say campaign-plan.zip. Upload it as it is. Don't unzip it.

  4. Repeat for each skill you want. One zip is one skill.

  5. Use it. Check the switch next to the skill is on. Start a new chat and name the skill in your request.

If Claude.ai refuses the upload

Claude's help page says a skill's description should be 200 characters or less. These eight have descriptions of 278 to 343 characters, so Claude.ai might reject them. We haven't been able to test it on every account.

If yours says no, you have two ways in:

  1. Use Claude Code, below. It takes the skills as they are.
  2. Attach the file instead. In any Claude chat, attach the SKILL.md file from the marketing-skills folder and write: "Follow the instructions in this file." Then ask your question.

Install in Claude Code (about 2 minutes)

Run these two commands in your terminal:

claude plugin marketplace add anthropics/knowledge-work-plugins
claude plugin install marketing@knowledge-work-plugins

Then type / in Claude Code and look for /marketing:campaign-plan. If it's there, you're set.

This route installs Anthropic's latest copy from GitHub rather than our zip. It also adds 13 connector entries for tools such as Slack, Canva and HubSpot. Prefer the zip? Copy the folders inside marketing-skills into ~/.claude/skills/ for yourself, or into .claude/skills/ inside one project.

Your 7-day list

About 20 to 30 minutes a day. Tick each day off. Your ticks stay on this device.

One example prompt per skill

Swap in your own business. In Claude Code you can also type the skill as a command, like /marketing:seo-audit.

brand-review

Use the brand-review skill. We talk to customers in a warm, local way with no jargon. Check these three Instagram captions and tell me what to change. [Paste the captions here.]

campaign-plan

Use the campaign-plan skill to plan four weeks of Facebook and WhatsApp posts for my bakery in Durban. The goal is more birthday cake orders.

competitive-brief

Use the competitive-brief skill to compare my guesthouse in Knysna with [competitor name and website]. Where are they stronger, and where can we win?

content-creation

Use the content-creation skill to turn this week's special into an Instagram post, a WhatsApp status and a Facebook post. The special is: [describe it here].

draft-content

Use the draft-content skill to write a short blog post on choosing a school uniform supplier in Pretoria. Give me five headline options.

email-sequence

Use the email-sequence skill to write three follow-up emails for people who asked for a quote on our garden service but didn't book.

performance-report

Use the performance-report skill. Here are last week's numbers: [paste reach, messages, enquiries and sales]. What worked, and what should I try next week?

seo-audit

Use the seo-audit skill to check [your website address]. List the fixes that will help people in Bloemfontein find us on Google, most important first.
